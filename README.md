# ATCsim
Проект з предмету програмна інженерія. Це симулятор розподілення рузу авіарейсів. Учасники: Безкоровайний Олександр, Борков Максим, Рубан Владислава. 
Суть проекту: 
З часом в повітрі стає все білше і більше авіарейсів, тому ми створюємо симулятор алгоритму,
який може наглядно показувати, як відбуватимется комунікація між літаками, та як вони будуть діяти.
Додаток з себе представлятиме інтерфейс, де можна побачити журнал радіообміну між авіарейсами,
рух літаків, та іншу інформацію. Буде видно інформацію про аеропорти, та велика мапа,
де можна відстежувати рух кожного авіарейсу. Користувач також зможе вручну добавити рейс, добавити/модифікувати/видалити аеропорт,
та змінити такі параметри, як вітер/нельотну погоду/інші погодні ситуації.
