## Про проєкт

Зростання щільності повітряного трафіку вимагає ефективних алгоритмів координації та запобігання колізіям. **ATCsim** — це десктопний програмний комплекс для моделювання, візуалізації та аналізу процесів керування повітряним простором.

Система демонструє принципи взаємодії між повітряними суднами і диспетчерськими службами, протоколи радіообміну, а також реакцію системи на зміну зовнішніх метеоумов у режимі реального часу.

## Швидкий запуск

На **Windows x64** запустіть `ATCsim.exe` подвійним кліком. Готова локальна збірка лежить у `artifacts/ATCsim-win-x64/ATCsim.exe`. Файл містить .NET, бібліотеки та демонстраційні сценарії. Для запуску достатньо скопіювати один EXE.

Натисніть **Run**, щоб запустити симуляцію, або **Pause**, щоб призупинити її. Кнопка швидкості перемикає режими **1× → 2× → 4× → 8× → 16× → 1×**.

Нова локальна база SQLite зберігається у `%LOCALAPPDATA%\ATCsim\Data\atcsim.db`. Якщо поряд із програмою вже є `atcsim.db`, ATCsim відкриває цю базу. Щоб зберегти поточну сесію й закрити програму, натисніть червону **✕** на панелі керування.

## Основний функціонал

- **Радар і телеметрія.** Поточні позиції, курси, висоти та траєкторії літаків. Коліщатко масштабує карту, а перетягування правою кнопкою миші зміщує її. Підписи аеропортів перемикаються через **View → Show airport labels**.
- **Керування трафіком.** Додавання рейсів, зміна курсу й висоти, прямування до аеропорту призначення та команда очікування. Симулятор прогнозує зближення, перевіряє маневри щодо погодних і закритих зон та веде журнал радіообміну.
- **Аеропорти.** Вкладка **Airport** показує смуги, зайняті стоянки, заправку та рух літаків. **Edit Airport** змінює напрямки, довжину й доступність смуг. Зустрічні напрямки однієї смуги мають спільну чергу.
- **Виліт і посадка.** Перед вильотом літак дозаправляється за оцінкою маршруту, зустрічного вітру, затримки на прибутті та запасу пального. На підльоті зниження починається ще на маршруті, а глісада перехоплюється на фінальній прямій. Слід на радарі зникає через п’ять секунд симуляції після посадки.

## Сейви та пресети літаків

У меню **File** команди **Export map save…** та **Import map save…** працюють із файлами `.atcsave`. Сейв відновлює карту за сідом і версією рельєфу, а також аеропорти зі смугами, погодні зони, літаки з їхніми траєкторіями, час і швидкість симуляції.

**Export aircraft preset…** зберігає склад літаків, їхні маршрути та початкові параметри у файлі `.atcpreset`. **Import aircraft preset…** замінює весь флот на поточній карті. Аеропорти маршрутів мають бути на карті й визначаються за кодом ICAO. Траєкторії починаються заново.

### Готові сценарії

| Файл | Як відкрити в меню **File** | Початковий стан |
| --- | --- | --- |
| [Eight-Airports.atcsave](src/ATCsim.UI/Saves/Eight-Airports.atcsave) | **Import map save…** | 96 літаків на стоянках, по 12 у кожному з восьми аеропортів. Деякі аеропорти мають дві або три смуги. |
| [Dense-256.atcpreset](src/ATCsim.UI/Presets/Dense-256.atcpreset) | **Import aircraft preset…** | 256 літаків уже в повітрі, серед них Ан-225 «Мрія» з позивним ADB225. Пресет використовує аеропорти стандартної карти. |

Після імпорту натисніть **Run**. Для власного пресету експортуйте поточний флот і відредагуйте список `data.aircraft` у JSON. Кожному літаку потрібен унікальний `callsign`. Координати `x` та `y` задають старт у повітрі. Якщо обидва поля пропущені, літак почне на стоянці.

## Збірка з вихідного коду

Проєкт використовує **C#**, **.NET 10**, **WPF** і **SQLite**. Для збірки потрібен **.NET SDK 10** на Windows. Усі команди виконуйте в корені репозиторію.

```powershell
dotnet build ATCsim.sln -c Release
dotnet test ATCsim.sln -c Release
dotnet run --project src/ATCsim.UI/ATCsim.UI.csproj -c Release
```

Для запуску з IDE відкрийте `ATCsim.sln` і виберіть **ATCsim.UI** як стартовий проєкт.

### Публікація одного EXE для Windows x64

```powershell
dotnet publish src/ATCsim.UI/ATCsim.UI.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -p:DebugType=None -p:DebugSymbols=false `
  -o artifacts/publish-win-x64
```

Команда створює `artifacts/publish-win-x64/ATCsim.UI.exe`. Для поширення скопіюйте цей файл. За потреби перейменуйте його на `ATCsim.exe`.

## Генерація карти за сідом

У верхній панелі введіть ціле 64-бітне число в поле **SEED** і натисніть **↻**.
Кнопка **Random seed** обирає новий сід та одразу створює карту. Після генерації
симуляція стоїть на паузі. Натисніть **Run**, щоб почати рух.

Сід визначає берегову лінію, ділянки рельєфу, розташування п’яти аеропортів,
напрямки та довжини смуг, погодні зони й початкові
маршрути та параметри восьми літаків. Аеропорти розміщуються на суші з відстанню
щонайменше 110 одиниць карти. Згенерована карта умовна й використовує назви реальних аеропортів.

Наприклад, згенеруйте `12345`, потім `98765`, а тоді знову `12345`:
початкові об'єкти й рельєф першої та третьої карти збігатимуться.
Команди диспетчера та час симуляції впливають на подальший рух, а не на генерацію.
Для відтворення використовується власний алгоритм SplitMix64 з усіма 64 бітами сіду.
Сіди попередньої демонстраційної версії створюватимуть нові карти за оновленим алгоритмом.

Згенерований сектор зберігається в SQLite. Команда **Direct to destination**
направляє вибраний літак до аеропорту призначення його згенерованого рейсу.

## Іконки та типи літаків

Логотип із `docs/logo.png` відображається зліва перед полем SEED. Кнопки керування
розташовані праворуч і переносяться на наступний рядок у вузькому вікні.

До пасажирських Boeing 737-800, Airbus A320/A321 та Embraer E195 додано:

- **Bombardier Global Express (GLEX)** — бізнес-джет.
- **Cirrus SR22 (SR22)** — легкий гвинтовий літак.
- **Antonov Ан-225 «Мрія» (A225)** — важкий транспортний літак. На радарі він має блакитну лінію курсу та український прапор біля назви.

Усі типи доступні в **Add Aircraft**. Генератор карти додає початковий трафік, а готові сценарії **Dense-256** і **Eight-Airports** містять «Мрію».
Після вибору моделі форма підставляє відповідні швидкість і висоту. При перемиканні
моделі форма зберігає вручну відредаговані значення.
Команди набору висоти враховують максимальну висоту моделі. Витрата пального
масштабується за місткістю бака як спрощена симуляційна оцінка. Інспектор показує
відсоток заповнення бака та оцінку запасу часу.

На карті використовуються окремі векторні силуети пасажирського, регіонального,
вантажного, бізнес- та гвинтового літака. Силует повертається за курсом,
а аеропорти позначені диспетчерською вежею з терміналом.
Літаки накладені безпосередньо на карту без квадратних підкладок. Тонкий світлий
контур забезпечує видимість на темному рельєфі. Кільце навколо силуету позначає
наведення, вибір або конфлікт. Прозора область натискання зберігається.
Натискання на значок або підпис аеропорту відкриває його інспектор.
